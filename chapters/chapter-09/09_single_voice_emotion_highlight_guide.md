## Can I add them for you automatically?

**In web UI:** No — you must highlight manually. There is no `[happy]` text tag in native MiniMax web UI. Those bracket tags only work in Morphic/other wrappers.

**Via API:** Yes — if you use MiniMax API directly, you can send:
```json
{
  "model": "speech-2.8-hd",
  "text": "Young Master Fang Zheng, this room was specially tidied...",
  "voice_id": "female-soft",
  "emotion": "happy"
}
```
Change `emotion` per block, same `voice_id` for single voice. I can generate that JSON file for you if you want to call API instead of clicking UI.
