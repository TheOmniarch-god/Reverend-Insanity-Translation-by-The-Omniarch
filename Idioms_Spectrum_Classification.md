# Idioms Spectrum Classification — Preface + Ch 1-6
## New Rule: Purely figurative = must figurative | Dual = literal OR English equivalent | Near-literal = literal OK
### Principle: Match function in context. If English equivalent reads more naturally, use it. If literal carries cultural flavor, keep it. Avoid literal that confuses.
