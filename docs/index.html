About This Project

The Omniarch Translation is an independent fan project working a full re-translation of Reverend Insanity (蛊真人), written by Gu Zhen Ren. It is not affiliated with the author or any official publisher. All rights to the original work belong to its author, and we ask only that readers support the original wherever they can.
